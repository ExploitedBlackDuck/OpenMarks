# OpenMarks demo vault

This isolated vault contains 100 neutral sample bookmarks across eight collections. The sample notes are clearly marked as demonstration data. You can edit or delete them freely.

Open **OpenMarks** from the ribbon or run **Open bookmark manager** from the Command Palette. Search, collection navigation, favorites, unread status, sorting, and all four display modes are available. Cached favicons work offline when present; unsupported or unavailable icons use the built-in fallback. OpenMarks does not download webpage preview images because it cannot safely constrain redirect destinations. Any preview files already cached in this vault remain available.

This vault is separate from any other Obsidian vault. OpenMarks does not restrict what lawful HTTP or HTTPS sites you save.
